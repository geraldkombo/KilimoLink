# World Bank FLLoCA / KJET Application Content
**Focus:** Locally Led Climate Action | **Pool:** $30M+

## 1. Project Title
**KilimoLink: Decentralized Logistics for Urban Carbon Reduction**

## 2. Alignment with FLLoCA Mandate
The "Financing Locally Led Climate Action" (FLLoCA) program requires verifiable local impact. KilimoLink provides this through:
- **Food Mile Decarbonization**: By forcing a 5km radius logic, we significantly reduce the transport emissions of the "Urban-Rural" bridge.
- **Waste Diversion**: Our real-time marketplace ensures produce is sold before it rots, addressing the 40% post-harvest loss in Kenya's informal supply chain.

## 3. Data-Driven Resilience
We provide the World Bank and KJET with a **"City Resilience Dashboard."** This dashboard (built with Recharts) visualizes:
- **Emissions Saved (kg CO2)**: Calculated based on distance reduced vs. traditional central markets.
- **Urban Green Space (m²)**: Every registered urban farmer maps their plot, giving city planners data on biodiversity corridors.

## 4. Financial Inclusion
By using the **Solana** blockchain for transaction records, we provide the "Missing Data" needed for KJET to issue green micro-loans to informal vendors.
