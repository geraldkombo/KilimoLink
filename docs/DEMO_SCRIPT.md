# KilimoLink Demo Script (Innovate4Cities 2026)

## Phase 1: Registration & Sourcing (0:00 - 1:00)
1. **Onboarding**: Login as a Farmer using Privy (email). Show the instant digital wallet creation.
2. **List Product**: Go to "Sell Your Produce". Enter details for "Organic Kale".
3. **Geolocation**: Use the Leaflet map to pin the farm location in Nairobi. Submit the product.

## Phase 2: Hyperlocal Marketplace (1:00 - 2:00)
1. **Discovery**: Switch to Buyer view. Grant location permissions.
2. **Nearby Badge**: Show the "Nearby" and "Ultra Local" badges on products based on the buyer's current coordinates.
3. **Product Detail**: View the Kale details. See the farmer's location and the transport savings.

## Phase 3: Transaction & Impact (2:00 - 3:00)
1. **Order Placement**: Place an order using the "Mock Payment" toggle for instant confirmation.
2. **Solana Demo**: (Optional) Toggle "Pay with Solana" to show devnet transaction integration for global payments.
3. **Impact Dashboard**: Go to the Admin Dashboard. View the real-time updates to CO2 Saved and Waste Diverted charts as the order completes.

## Conclusion
"KilimoLink is turning our cities into resilient, hyperlocal food hubs. Join us in building the green urban future."
