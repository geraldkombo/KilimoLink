# User Manual (Agribusinesses)

## 1. Register and Verify Phone

1. Enter your phone number.
2. Receive a one-time code (OTP) via SMS.
3. Verify the code to access the platform.

## 2. Create Your Business Profile

Update:
- Youth-led / Women-led status
- Business type (crops/livestock/value addition)
- Sector and county
- Business size
- Optional AGPO certificate reference

## 3. Value-Addition Hub

Access expert-led courses and resources focused on processing, packaging, and branding. These materials are curated by **private agribusiness mentors and successful value-addition entrepreneurs** to help you increase your profit margins and reach urban consumers more effectively.

## 4. Market Linkage

List products for sale and receive buyer orders.
